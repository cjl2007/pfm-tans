PFM-TANS Python workflow dependencies

Runtime:
- Python with PyYAML, NumPy, SciPy, nibabel, matplotlib, Pillow, and trimesh.
- SimNIBS 4.5: CHARM, its Python environment, and configured coil models.
- Connectome Workbench: wb_command for surfaces and E-field mapping.
- FSL: convert_xfm for affine inversion; fslmerge for simulation outputs.
- FFmpeg for search-replay movies.
- Completed upstream anatomy and PFM inputs; packaged res0urces data.

Optional maintenance/testing:
- XlsxWriter for calibration spreadsheets.
- Node.js and Google Chrome for browser regression scripts.
- systemd/journalctl for background-service completion receipts.

The generic YAML templates require your SimNIBS/Workbench paths and matched hardware.
See docs/INSTALL.md for installation links and config-copy instructions. TANS_PYTHON selects
the orchestration interpreter; simulation.simnibs_python selects the simulation
environment. No MATLAB runtime or MATLAB toolbox is needed.
